Minecraft Bash Forge Server Installer

This script will download and install Minecraft Forge version 26.3



IMPORTANT INFORMATION
-----------------------------------------------
Operating system support          | yes/no |
-----------------------------------------------
Ubuntu Linux Operating systems     | Yes |
-----------------------------------------------
Windows 7/10/11                    | No |
-----------------------------------------------
Android                            | No |
-----------------------------------------------
DO NOT RUN THIS BASH SCRIPT AGAIN AFTER RUNNING IT ONCE!

In order to run the server after shutting it down after running the install script, go to your teminal on linux and type the following commands,

cd ~/Documents

cd /Minecraft-Server

bash ./run.sh
